# SNMP - Authentication

## Practical

If you have captured some network packets that is used to authenticate the SNMP exchange then you can brute for the password using the **snmpv3brute** tool.

### snmpv3brute.py

```
python3 snmpv3brute.py -w <wordlist> -p <snmp.pcap>
```
